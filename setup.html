Setup backend dari HP

Semua bisa dilakukan dari browser HP — cukup salin-tempel dua blok kode di bawah ke Google Apps Script, lalu tempel URL hasil deploy ke kotak simpan.

1

Buka Apps Script & buat project

Buka script.google.com/create di browser HP (login akun Google bila diminta). Project baru akan terbuka dengan file Code.gs berisi kode default.

2

Ganti isi Code.gs

Di editor, hapus semua isi Code.gs, lalu tekan tombol salin di blok ini dan tempel (tekan lama → Tempel):

Code.gs
Memuat…
3

Aktifkan & isi appsscript.json

Tap ikon ⚙ Project Settings (kiri) → aktifkan "Show 'appsscript.json' manifest file in editor". Kembali ke editor </>, tap panah di sebelah Files → pilih appsscript.json → ganti isinya dengan blok ini:

appsscript.json
Memuat…
4

Jalankan setupDatabase (sekali)

Di editor, tap dropdown ▼ di toolbar → pilih setupDatabase → Run. Saat diminta izin: Review permissions → pilih akun → Advanced → Go to … (unsafe) → Allow. Database Google Sheets dibuat otomatis — tidak perlu menyalin ID apa pun.

5

Deploy sebagai Web App

Tap Deploy (kanan atas) → New deployment → tap ⚙ → pilih Web app. Isi: Execute as: Me, Who has access: Anyone → Deploy → salin URL yang berakhiran /exec.

6

Simpan URL ke Saklar

Tempel URL /exec di sini — tersimpan ke konfigurasi preview dan ke perangkat ini (situs publik GitHub Pages otomatis memakainya):

💡 Setelah URL tersimpan, buka Dashboard → daftar/masuk → isi API key AI dan token bot. Setiap kali kode backend di repo diperbarui, ulangi langkah 2–3 (salin-tempel lagi) — URL deploy lama tetap berlaku selama kamu memakai Manage deployments → Edit, bukan deployment baru.
