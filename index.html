Saklar AI CS-mu untuk Telegram & WhatsApp.

Tempel API model AI dan token bot-mu ke Saklar — setiap pesan pelanggan dijawab otomatis oleh agen AI. Backend-nya cuma Google Apps Script, database-nya Google Sheets. Tanpa server, tanpa ribet.

Nyalakan sekarang

Tiga colokan, satu saklar

Sambungkan otak AI dan kedua kanal chat — Saklar yang urus koneksinya.

Koneksi AI fleksibel

Pakai Gemini, OpenAI, atau penyedia kompatibel lain. Cukup tempel API key dan instruksi agen — tanpa sentuh kode.

Bot Telegram

Tempel token dari @BotFather, nyalakan saklar — webhook terpasang otomatis dan bot langsung siap menjawab.

WhatsApp Business

Terhubung ke WhatsApp Cloud API resmi dari Meta. Verifikasi webhook otomatis, pesan masuk langsung dibalas AI.
