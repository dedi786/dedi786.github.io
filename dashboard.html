WhatsApp Cloud API

Butuh Meta for Developers: buat app → tambahkan produk WhatsApp → ambil Phone number ID dan token.

Kosongkan jika sudah tersimpan dan tidak ingin mengganti.
Tempel di Meta → WhatsApp → Configuration → Webhook, lalu klik Verify and save.
Aktifkan saklar WhatsApp Saat dinyalakan, backend berlangganan pesan masuk nomor WhatsApp-mu.
  1. Isi Phone number ID, token, dan verify token, lalu simpan.
  2. Salin callback URL di atas → tempel di Meta → klik Verify and save (backend membalas challenge otomatis).
  3. Di halaman yang sama, klik Subscribe to the field messages.
  4. Nyalakan saklar, kirim pesan ke nomor WhatsApp-mu. Selesai! 🎉
